# empreendedorismo

No trabalho para a disciplina de empreendedorismo eu estou explorando o uso de inteligência artificial offline. Para isso eu criei um pequeno programa para salvar tarefas em uma lista. Este programa utiliza o ollama para classificar a mensagem do usuário entre adicionar um novo item a lista ou mostrar a lista. Quando o ollama identifica que a mensagem é para adicionar um novo item na lista ele identifica qual parte da mensagem deve ser salva. Esse programa é apenas uma demonstração, o objetivo é criar um script que permita configurar o ollama de forma facilitada para ser usada em qualquer tipo de programa.
